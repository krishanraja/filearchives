## Operational lessons encoded in the engine

- recursive classification and mutation are separate manifest boundaries;
- cloud destination readback retries eventual-consistency failures;
- system metadata is excluded at the copy boundary even when an earlier path
  classifier assigns a different category;
- credential-like files can move to same-volume secure quarantine without
  opening or hashing their content;
- live-file copy retirement authenticates the exact source root from the copy
  manifest rather than guessing it from the first file;
- long live-file copies journal each completed file and safely resume from
  already verified destinations;
- provider/reparse shells are not treated as normal directories, and an
  unavailable or unreadable object is never treated as empty.
- heterogeneous run directories are prefiltered by owned evidence kind before
  JSON deserialization;
- quarantine planners reserve every destination before execution so same-name
  rows cannot collide;
- a locked empty shell is recorded without aborting independently safe empty
  cleanup targets;
- dirty-repository snapshots array-normalize Git output and finally reconcile
  the complete file set, every hash, status, index and full HEAD;
- raw Git-index bytes are checked immediately, while durable final proof uses
  staged-entry semantics because `git status` may refresh stat-cache bytes.
